Magewire's JavaScript release process is maintained in a private project and is not part of the public extension API.
The previous instructions on this page linked to an inaccessible repository and could not be followed from a public
Magewire checkout.

Use the JavaScript bundles shipped with the current `magewirephp/magewire` release. If you are contributing a browser
runtime change, coordinate with the Magewire maintainers so the matching source, patches, manifest, and generated assets
are updated together.

See [Portman](../../advanced/architecture/portman.md) for the supported PHP porting workflow.
